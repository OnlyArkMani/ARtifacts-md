# 99_INTERVIEW_TRAPS_AND_MISTAKES

1. Overview

A curated list of common interview pitfalls across algorithms, systems, and languages with quick mitigation strategies.

2. Key traps (examples)

- Not clarifying constraints (n, data types, memory) — ask and state assumptions
- Ignoring edge-cases: empty inputs, single-element arrays, duplicates, overflow
- Choosing wrong data structure: prefer correct abstraction over micro-optimizations
- Premature optimization vs algorithmic change
- Off-by-one errors and loop invariants

3. Communication traps

- Not talking through thought process; write small examples and reason about complexity
- Not testing with examples or failing to walk through code

4. Language-specific traps

- Java: forgetting about autoboxing, NPEs, mutation of shared objects
- Python: mutable default arguments, unintended copies, performance pitfalls with loops

5. System-design traps

- Not scoping the problem, missing constraints, ignoring non-functional requirements (latency, availability)

6. Final checklist before submitting

- Complexity analysis, edge-case tests, brief notes on tradeoffs and scaling
