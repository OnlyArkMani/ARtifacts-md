# 31_RANDOMIZATION_AND_PROBABILISTIC_ALGORITHMS

1. Introduction

What this concept is

Randomized algorithms use randomness to simplify algorithms or improve expected time; include Las Vegas (always correct, expected time bound) and Monte Carlo (probabilistic correctness).

Why it exists

Simplify complex deterministic solutions, achieve better average-case performance, or handle adversarial inputs.

Examples

- QuickSort randomized pivot
- Bloom filters, randomized hashing
- Reservoir sampling for streaming


2. Interview Qs

- Implement reservoir sampling
- Explain tradeoffs of Monte Carlo vs Las Vegas algorithms


3. 5-min revision

Randomization often reduces worst-case degeneracy and simplifies algorithms; account for probability of failure using amplification.
