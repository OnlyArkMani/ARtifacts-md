# 38_PANDAS

1. Introduction

What this concept is

Pandas provides DataFrame for tabular data manipulation: joins, groupby, aggregation, time-series operations.

Why it exists

High-level data wrangling and analysis with vectorized operations and expressive APIs.


2. Tips

- Use categorical dtypes for string-like repeated columns
- Avoid row-wise operations; use vectorized or groupby-apply carefully


3. 5-min revision

Balance expressiveness with performance; profile groupby and joins.
