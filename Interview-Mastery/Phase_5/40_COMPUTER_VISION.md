# 40_COMPUTER_VISION

1. Introduction

What this concept is

Computer vision covers image processing, convolutional neural networks, feature detection, object detection, segmentation.

Why it exists

To extract semantic and geometric information from images and video.


2. Key techniques

- Convolutional architectures (ResNet, EfficientNet)
- Transfer learning and augmentation
- Object detection frameworks (Faster R-CNN, YOLO)


3. 5-min revision

Start with pretrained models, fine-tune, apply augmentations and proper evaluation metrics (mAP, IoU).
